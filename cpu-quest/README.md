# CPU Quest · 从沙子到程序

一个本地的「打怪升级」式计算机体系结构学习网站。从一粒沙子(晶体管)一路造到操作系统,
11 个世界 / 19 关 / 84 道 Boss 题 / 16 个可动手模拟器,通关升到顶级「体系结构大师 👑」。

## 怎么启动

在项目目录里起一个本地静态服务:

```bash
cd /home/pc/cpu-quest
python3 -m http.server 8765
```

然后浏览器打开 **http://localhost:8765**

> 端口 8765 被占用的话,换个数字即可(比如 `python3 -m http.server 8080`,
> 再访问对应端口)。

## ⚠️ 别直接双击 index.html

本站靠 URL 的 `#/lv/xxx` 做路由、靠浏览器 localStorage 存进度。
用 `file://` 直接打开,某些浏览器会限制 localStorage,**进度可能存不住**。
请务必用上面的 http 服务方式打开。

## 进度与存档

- 通关记录、XP、等级、徽章全部自动存在浏览器 localStorage,关掉再开还在。
- 想从头再来:地图页最底部有「🗑 清空进度重新开始」按钮。
- 换浏览器或清了浏览器数据,进度会丢(存档只在本机这个浏览器里)。

## 玩法

- 每关末尾有 **Boss 小测**,答对拿 XP、答错不扣分只给解析。
- 关卡按顺序解锁,通关上一关才能进下一关。
- 带 ⚡ 的关卡有**可以动手玩的模拟器**(逻辑门、加法器、迷你CPU单步执行、
  缓存命中率对决、递归调用栈、虚拟内存翻译机等),是本站精华,别跳过。
- 序章说明:某关一眼就懂,可直接答 Boss 题拿 XP 跑路,不用逐字读。
